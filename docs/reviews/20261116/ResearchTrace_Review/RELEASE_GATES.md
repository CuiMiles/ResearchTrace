# 提交前准入检查

以下是本项目内部发布门槛，不是官方打分表。按原件 AI35/工程30/创新15/UX10/实用10 建证据，不自行捏造子项分数。

## A. 不能带到评审现场的阻塞

- [ ] 官方39PDF和新输入均可正常导入；一次选择20篇可分批完成，不受10任务硬上限永久阻止。
- [ ] 活动解析内容完成受控索引，覆盖率有分母；中文自然提问能检索英文原文。
- [ ] 空引文被拒绝；8→80数字反例、自由answer绕过和无答案问题有回归。
- [ ] 所有事实段落有claim映射；证据“定位成功”与“支持主张”不同状态。
- [ ] 第一配额项目耗尽能评估其他独立授权项目；全局预算不会被绕过。
- [ ] judging模式不受历史4次smoke永久封锁；账目不清空；默认不自动付费。
- [ ] arXiv/Crossref至少一条真实新查询和真实全文导入；全部来源失败不当成搜索成功。
- [ ] 中→英与英→中独立缓存；公式/代码/引用标记完整。
- [ ] 长文解析、索引期间仍能读取PDF并处理交互任务；失败可恢复，不覆盖旧引用。
- [ ] 评委稳定登录、刷新/重新登录可回到授权工作区；新浏览器能找到演示入口。
- [ ] 外网HTTPS真实可访问，API/模型/索引/worker状态不混为一个绿色健康点。

- [ ] 至少一个Agent任务根据中间证据调整计划；工具结果真实进入后续决策。
- [ ] 至少一个旧FutureWork到后续全文的自动链路；时间未知/同年/部分覆盖正确处理。
- [ ] 新旧版本对已生成主张的影响有真实来源，历史笔记不被改写。
- [ ] 图/表问题具备真实视觉或结构化证据；不把页级定位伪装成单元格定位。
- [ ] 1280/1440/1920下关键页面可读，答案优先、过程可展开、图谱边可核验。

## 评测口径

检索建议80题；先控制切分对比模型，再单独比较结构切分/重排/视觉。无答案题不计入有答案Recall分母。语义支持率按原子事实主张计算，另报遗漏率、拒答/纠错和数字条件正确率。人工检查不能只看有没有引文，必须读该引文是否支持结论。生成质量的小批真实调用使用独立预算，检索测试优先全部本地完成。

只有A全部关闭、C交付齐全，且三条核心演示没有BLOCKED，才称“基本可提交”。B用于提升竞争力，但不能保证第一名。
