## 部署兼容性要求

- 固定模型commit/revision与依赖锁；下载后的remote code先审阅，禁止不固定版本的随意trust_remote_code。
- 独立Transformers环境优先。当前官方3.5示例要求注意Transformers5.20.0与vLLM示例所需区间的分离，部署时重新核对官方精确要求，不把两套依赖强行混装。
- 首次3090 smoke：batch1、短文本；之后再测2048/4096输入长度及图像。8B BF16权重约16GB，不等于运行峰值；依据真实空闲显存和2GB安全余量分配，不能假设8张卡都空闲。
- 两个8B模型通常需要分别安排资源槽或明确串行换载；不承诺同卡常驻。每模型自己的预算、并发和超时，保留他人GPU进程。
- 不将NVFP4当作3090默认。量化仅在BF16基线已记录且质量/兼容性测试通过后采用。
- 服务故障时保证PDF阅读、原文检索与历史产物可用；复杂AI操作明确降级，不以旧结果冒充新调用。

## 评测与发布准入

80条检索题（24事实/16跨语言/12多文/12图表公式/8版本/8无答案或错误前提），人工gold独立核对。按work分调参与保留测试集；同一论文不同版本不跨集合泄露。官方39PDF做兼容性，另加未见论文做泛化。
