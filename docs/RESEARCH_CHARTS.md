# Discovery, local citation graph and controlled plotting

`services/api/research.py` implements live arXiv Atom and Crossref REST searches, source-labelled candidates, DOI/arXiv identity revalidation before import, real accessible PDF download, metadata-only failure states, persistent query caching, recommendation feedback, watch checks and local citation graphs. arXiv calls share a file lock across processes, one connection at a time, with a gap of at least 3.1 seconds after completion. Crossref calls have a one second gap. Failed-only queries do not become successful empty cache entries. Search cache is marked with original retrieval time; workspace feedback is reapplied after reading public metadata cache.

HTTP fetches validate all resolved addresses, reject nonpublic/mixed DNS, only permit HTTP(S) ports 80/443, pin the request URL to a validated public IP and retain original Host/TLS SNI, and repeat validation for each redirect. Downloads have byte/redirect/time limits. Operator-configured `RT_PUBLIC_PROXY` or `RT_PROXY` is supported, including the already running SOCKS proxy; user input cannot set a proxy. No provider credentials enter public requests. There is no arbitrary shell or repository execution.

Graph edges come from parsed bibliography identifiers or unique complete titles, with the actual `ref_id`, source version, physical page and block preserved. Crossref deposited-reference DOI edges explicitly link back to their source metadata endpoint; those edges have no fabricated PDF page. PageRank uses damping .85, handles dangling nodes and explains that rankings are local centrality, not scholarly quality. No vector similarity edge is called a citation.

`services/api/charts.py` validates a closed Pydantic PlotSpec and CSV data (UTF-8/GB18030, bounded columns/rows/bytes, unique headers, structural errors, missing/nonfinite values). Statistical summaries use actual finite values and preserve row/count diagnostics. Missing line values make gaps, with warnings. 3D needs three distinct complete numeric columns; radar needs at least three complete metrics and explains normalization. Captions contain computed maxima/deltas, valid sample counts and an explicit absence of statistical/causal testing.

Rendering runs a fixed Python template in a bounded subprocess (resource limits applied at child startup, avoiding preexec hooks in the threaded API), with no user/model code interpolation, no shell, no provider secrets in the child environment, 768MiB address-space cap, CPU/file/time bounds and one BLAS thread. TeX execution is disabled. Font cache is shared nonprivate state to avoid rebuilding the host font index for each chart; Latin and CJK font fallback keeps labels readable. The child validates completed PNG/SVG files and exits directly after closing output handles, avoiding costly C-extension interpreter cleanup. Numeric line axes use actual numeric positions; categorical axes are explicitly labelled in PlotSpec and diagnostics. Files are authenticated by artifact workspace and a fixed filename allowlist. Exports include original CSV, SHA256-bearing PlotSpec, PNG, SVG and a standalone reproduction script.

Tests use explicitly synthetic fixtures and do not claim upstream availability.
- `docs/evidence/chart_numeric_axis_tests.txt`: added quantitative-x versus categorical-x assertions, two different real CSV figures and independent script reproduction; 1 passed, 16 deselected in 45.14s.
- Earlier rendering tests exposed repeated font-cache CPU cost, CJK-only font missing Latin digits, and interpreter finalization exceeding the child CPU limit after successful image writes. Shared font cache, Latin/CJK fallback, fixed plot margins and verified-output direct process exit corrected these before the passing run. No fabricated chart fallback was used.
- `scripts/prepare_evals.py --download` fetched original arXiv Transformer v7/v1 under random filenames plus BERT v2, and generated explicitly derived scan/541-page engineering inputs, independent CSVs and corrupt/encrypted/adversarial fixtures. `evals/manifest.json` contains sources, hashes, licenses, timestamps and original/derived labels. Official scan and official textbook remain BLOCKED; metadata records are not claimed as 20 full PDFs.

Full remote HTTP retries are deliberately absent: 429 includes Retry-After and remains a visible source error; no identity cycling or unbounded retry. A scheduled watch is driven by the root worker, default disabled. Code links are clues only; repository training/evaluation execution is not performed.
