# 研证 ResearchTrace 技术报告源稿

状态：可编辑源稿。**正式参赛 PDF、演示视频和平台提交尚未由本文件生成或完成**。目标为省赛实际竞争力，不能承诺名次。功能及测试以源码和 `docs/TEST_REPORT.md` 为准。

## 1. 实际问题与产品闭环

科研助手常见失效点是结论无法回到原文、同一论文不同版本混用、旧 Future Work 被当成今天尚未解决的问题、数据图与原始数值脱节。本项目将问题落实到可检查对象：一个研究作品、不可变版本、物理页、文本块坐标、逐字引用、主张类型和有时间范围的后续检索。

主路径是新 PDF 导入后逐页解析和持久化，阅读器显示原版，检索候选进入一次综合分析，结果经过引用身份与原文匹配验证，用户可从结论打开具体版本原文。其他路径围绕同一工作区扩展为翻译、跨文比较、学术检索、引用图谱、研究建议审查、研究笔记和真实 CSV 图表。

## 2. 轻量工程架构

前端为 React、TypeScript、Vite、PDF.js；API 为 FastAPI/Pydantic；SQLite WAL 持久化元数据、块索引、嵌入向量、任务与额度；本地文件保存 PDF 和产物。单 worker 处理耗时任务。文档原生文字由 pdfplumber 提取，低文字页使用实际可用的 CPU OCR。没有模型训练、常驻本地 LLM、Redis、大型向量服务或 GPU 依赖。

设计部署目标为约 2vCPU/2GiB。长文按页提交并释放处理资源，阅读器分页，嵌入批次受条数与字节约束；容器配置资源上限，不能将配置上限当成实测峰值。组件、失败恢复和运行边界见 `ARCHITECTURE.md` 与 `DEPLOYMENT.md`。

## 3. 版本感知的证据链

同一 Work 下保存多个不可变 Version。字节哈希识别重复；内容中的 arXiv/DOI 与版本信息辅助关联，而不是依赖文件名。未知版本不依上传先后强行排序。文档更新后，旧问答仍绑定旧 version/block/page，不静默替换其来源。确定性段落 diff 给出真实增加、删除和修改。

Evidence 包含版本、块、物理页、标准化 bbox、逐字引用和定位状态。来源事实必须有引用；不存在的块或无法匹配的 quote 被拦截。位置已找到与语义充分支持是两类结论，当前语义仍需模型辅助或人工核查。该边界避免用“引用 ID 存在”冒充事实准确率。

## 4. 检索与模型职责

FTS5/BM25 提供稀疏候选；已验证 embedding API 生成真实密集向量，余弦排序后由 RRF 合并，并补入相邻条件/表头。模型或维度不同的向量不混用。稀疏和密集候选分别记录；密集失败明确显示关键词模式，不声称混合检索完成。

Hydrogen 用于核心综合分析；Flash Lite 负责批量翻译等工作。不需要模型的哈希、数值统计、引用计数、图算法和额度计算采用确定性程序。系统不会将替代模型显示成 Hydrogen，也不会伪造实时 token 流。公开运行事件显示实际工具步骤。

## 5. 研究建议核查

核查入口保留旧建议的具体块。系统记录查询、检索日期和 arXiv/Crossref 候选，再结合可用的其他全文证据，要求核对发表时间、研究任务及限制条件。状态区分直接相关证据、部分覆盖、当前检索范围证据不足和无法判断。候选标题或未搜到结果都不能支持“已彻底解决”或“全球首次”。

当前版本的自动后续文献时间条件核对与原文支持仍存在需独立核查的边界；真实案例完成情况见 TEST_REPORT。本文不把模块入口写成已通过两个代表性案例。

## 6. 引用图谱、写作与数据图

图谱边来源于真实解析参考文献或已核验 Crossref 登记引用 DOI，保留条目与来源位置/元数据链接。相似性不冒充引用。局部 PageRank 解释为当前集合中的相对中心性，断连不表示质量差。实际获取的一组20篇 Crossref 元数据产生20节点、71条登记引用边，证据在 `docs/evidence/graph_20_metadata.json`；这不是20篇全文或全领域评估。

研究笔记将事实主张与版本引用一起导出。CSV 经编码、列类型、结构和缺失值检查后，形成封闭 PlotSpec，由固定受控脚本绘制折线、柱状、雷达和合适数据的三维图。统计、Caption、最大值与差值来自程序计算；导出原 CSV、哈希、PlotSpec、PNG/SVG 和独立脚本，不执行模型任意 Python，不捏造误差条、显著性或因果关系。

## 7. 安全与额度

服务器环境保存密钥；会话与工作区鉴权贯穿文件、任务和产物。下载阻断私网、回环和云元数据，并逐跳验证、固定解析到的公开 IP。HTML、Markdown 和 Mermaid 采用受控渲染边界。文档、CSV 和搜索摘要是不可信数据，不能提升为系统命令。

调用前事务预留项目级 RPM、输入TPM、RPD；相同项目的多个 key 不增加额度，RPD 使用太平洋时区。失败、超时和未知调用记账。冒烟 Hydrogen 默认最多4次，后续评测需显式预算。付费兜底关闭，其他项目并行消耗无法由本地账本获知。输入token预算当前采用保守字节估计而非官方精确计数。

## 8. 验证、局限与复现

验收以 ACCEPTANCE.md 逐项记录 PASS/FAIL/BLOCKED/NOT RUN。新输入包括随机文件名的真实 Transformer v1/v7、另一个真实 PDF、两份不同数值 CSV、派生扫描件、自编541页工程压力文档及异常输入。官方扫描原件和指定教材缺失时仍标 BLOCKED，不能由派生材料替代。

17项图表/检索/重定向与DNS固定/追踪持久化局部测试实际通过（记录耗时140.38秒）；双数据源实时检索及20节点元数据图有独立证据。整体构建、浏览器尺寸、实际模型问答、长文内存、质量样本和API消耗由主测试报告汇总。没有独立真值集和基线实测前，不报告准确率提升、引用支持率或虚构性能数值。

复现命令、启动地址、三个输入路径、已知缺陷、外部阻塞和最少人工动作见 README、HANDOFF 和 TEST_REPORT。公网HTTPS、评审持续服务、正式视频/PDF和提交各有独立状态。本项目工程贡献是闭环整合和边界可检查；BM25、RRF、PageRank及第三方模型均保留原作者归属。
