\subsection{部署架构}

\subsection{部署与运维}

\begin{itemize}
  \item \textbf{一键启动。}本地开发执行 \code{./scripts/dev.sh}；服务器执行 \code{docker compose -{}-profile lite up -d}，加上 \code{https} 配置即可自动申请证书。未配置模型密钥时，导入、解析、阅读、检索、图谱与绘图仍然可用。
  \item \textbf{发布与回滚。}新版本构建为独立镜像，健康检查通过后才切换；失败不影响当前版本，数据与账本始终保留。
  \item \textbf{数据安全。}每日定时做一致性快照备份（SQLite 备份 API + 文件校验），保留最近 7 份；恢复流程有自动化测试覆盖。
  \item \textbf{评审账号。}支持签发带有效期的独立评审账号，每个账号进入各自隔离的工作区，并预置已解析与已索引的示例文献，开箱即用。
  \item \textbf{可观测性。}管理页展示 Worker 心跳、索引覆盖率、各模型当日用量与降级状态，以及逐项验收记录与原始证据。
\end{itemize}
