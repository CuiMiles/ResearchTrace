Retain each dependency's packaged copyright, license and NOTICE files when redistributing a built image or frontend bundle; this inventory does not replace those license texts. No GPU model weights or paper PDFs are committed as source assets.

## Data and external services

- arXiv metadata is provided under CC0 as described in [arXiv API Terms](https://info.arxiv.org/help/api/tou.html). E-print PDFs retain the individual author/publisher license; public download is not blanket permission to republish. Test PDFs remain in ignored `evals/files/`, and `evals/manifest.json` records source, SHA256, timestamp and derived/original status. Derived scans do not become official contest scan data.
- Crossref bibliographic metadata comes from its [REST API](https://www.crossref.org/documentation/retrieve-metadata/rest-api/). Individual abstracts/fulltext may retain copyright. Citation graph metadata records their source endpoints; they are not fabricated fulltext page evidence.
- Self-authored CSV and synthetic engineering PDF fixtures generated by `scripts/prepare_evals.py` are identified as CC0 test data. A synthesized 541-page engineering document is not the official textbook.
- Gemini is accessed as an external service under the operator's authorized credentials and applicable terms. No model weights or API keys are redistributed. The model name, local usage and limits are recorded separately from software license attribution.

The repository currently contains notices and integration source, not a grant of rights to redistribute third-party papers or private uploaded materials. A formal competition package should include this inventory and the corresponding dependency/data notices appropriate to what is actually shipped.

Preserve the release's bundled text when distributing.

- Torch, Transformers, Safetensors, CUDA runtime wheels, and parser transitive packages keep their bundled notices under the separate parser environments. `requirements-paddle.lock` and `requirements-mineru.lock` record the actual optional environments. The lite API does not require these large environments. Model distribution and all transitive notices must follow the actual assets included in a release; source integration alone does not redistribute weights.
